# 证据图质量对比：徐工机械、药明康德与赣锋锂业

## 1. 目的与样本边界

本文比较当前 Evidence Graph 规则与较早图谱输出的结构质量，关注的不是标的结论是否正确，也不是三家公司之间的基本面可比性，而是图谱能否清楚回答：**这条 Claim 被什么资料支持、有哪些限制、还缺什么数据。**

样本均来自本地 `backend/fever.db` 中 2026-08-20 的 team run artifact：

| 样本 | Artifact ID | 图谱版本定位 |
|---|---|---|
| 徐工机械（早期） | `43d689c139eb` | 较早的 Claim 生成方式 |
| 徐工机械（后期旧版） | `868d1a77dcc2` | 采用解读卡片/关键 Evidence 的旧版 prompt |
| 药明康德（旧版） | `4fc1bd2f8c9f` | 采用旧版边接口的较完整图谱 |
| 赣锋锂业（当前） | `8725ddbb15de` | 使用当前结构校验、标题检查、audit 和完整性优先 prompt 的样本 |

因此，赣锋锂业是当前实现的**可用观察样本**，并不是严格的 A/B 实验。标的、当时可获得的数据、模型随机性和工具调用顺序都会影响结果；后续仍应在同一问题、同一数据窗口下做重复运行比较。

## 2. 当前质量标准

当前图谱不要求“边越多越好”，而要求最低可审计闭环：

```text
Evidence → Claim → supports / contradicts → audit → export
```

具体检查包括：

- 每条保留 Claim 至少有一条 `supports` 或 `contradicts`；`context` 不能替代实质证据；
- `supports` / `contradicts` / `context` 只能为 Claim → Evidence；`addresses` 只能为 Evidence → Missing；
- 边要有 `note`，说明它具体支持、削弱或补足什么；
- audit 报告无实质证据 Claim、仅 context Claim、孤立 Evidence、未补足 Missing、重复边和无 note 边；
- Claim 标题进行软检查：过长、多个数字堆叠、多分句或混入 rationale 时提示改写，而不自动删除合理判断。

## 3. 结构指标对比

| 样本 | Evidence | Claim | Missing | 总边 | supports/contradicts | 有实质边的 Claim | 边有 note | 非法端点边 | 标题软警告 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|

“非法端点边”按当前规则回放旧 artifact 后得到：旧版药明存在 Claim → Missing 的 `addresses` 以及 Claim → Claim 的 `context`；它们在当时的实现中可以被创建，但不能准确表达现行关系语义。

## 4. 案例一：徐工机械——从“长结论挂单一证据”到更清晰的多维 Claim

### 早期样本

早期徐工图谱只有 3 条 Claim 与 3 条 supports 边，最基本的 Claim—Evidence 连接已经存在；但三个标题全部触发当前的笨重标题检查。

- C1 同时塞入“年报破千亿、Q4 利润骤降、Q1 利润增速滞后”等多个判断；
- C2 同时包含均线、回撤、基本面背离和两种未来路径；
- C3 同时讨论静态 PE、PB、动态 PE、机构预测与盈利兑现风险。

这些节点信息量高，却使读者难以判断某一条 Evidence 到底支持其中哪一个子判断。所有边也没有 note，图上只能知道“连了”，无法知道关系的理由。

### 后期旧版样本

后期旧版扩展为 5 条 Claim、8 条 supports、5 个 Missing。C1“增收不增利”、C3“股价与业绩背离”、C4“增持与事件催化”、C5“资金回流信号”等主题已被拆开；每条 Claim 都至少有实质 Evidence。

这是质量上的明显进步：Claim 从“大段综合判断”更接近可独立验证的研究问题，且 Missing 开始记录估值历史分位、相对收益、资金流持续性等不能安全推断的部分。

但它仍有两项结构不足：

1. 十条边的 note 全部为空，阅读者无法在图中快速理解每条连接的含义；
2. C3 标题仍因多个数字提示触发软警告，说明“原子化”尚未稳定。

## 5. 案例二：药明康德——覆盖较完整，但旧关系语义会误导阅读

药明康德旧版已经具备 5/5 Claim 的实质边覆盖：基本面修复、禁令事件、行情估值、机构筹码和估值都至少有一条 supports。这说明旧 prompt 并非不能构造图谱。

主要问题在于边语义与可读性：

- 15 条边均没有 note；例如读者无法从图本身知道 C2 与事件研究 Evidence 的关系是“事件日超额收益支持方向”还是“仅提供背景”；
- C2 → M1、C5 → M2/M3 使用了 `addresses`，但 `addresses` 的语义应是“新 Evidence 补足 Missing”，而不是“Claim 指出一个 Missing”；
- C3 → C1 使用 `context`，形成 Claim → Claim；它表达了“行情判断以基本面判断为背景”，但这并不是当前图模型允许的可追溯关系。

在当前模型下，上述四条边会被阻止。正确做法是：把导致 C2/C5 限制的资料整理成 Missing；只有新增 Evidence 真正补齐该缺口时，再以 Evidence → Missing 的 `addresses` 建边。C3 对基本面判断的依赖则应连接到对应的财务 Evidence，而不是连接另一个 Claim。

因此，当前结构校验的价值不在于增加边数，而在于避免图中出现“看起来有连接、实际无法追溯”的伪推理路径。

## 6. 案例三：赣锋锂业——当前闭环已经形成，但 audit 暴露了下一批改进点

赣锋锂业当前样本有 5 条 Claim、10 条 supports、3 条 context、1 条 addresses。五条 Claim 都有两条 supports，13 条边也全部带有可读 note；按当前端点规则回放，没有非法边。这是当前版本最直接的改善证据。

例如：

- C1“盈利处于锂价上行周期的弹性释放期”由 2026Q1 财务摘要和业绩反转事件摘要共同 supports；note 分别明确了“单季归母高于 2025 全年”和“2025H1 亏损至 2026H1 预告盈利”的事实；
- C3“市场尚未充分定价基本面反转”同时连接价格回撤/均线 Evidence 与相对收益 Evidence，并以财务资料作为 context，避免把“股价下行”直接等同于“基本面错误”；
- C4 估值 Claim 明确连接 EPS 一致预期与 PB 锚点，同时将锂价敏感性缺失保留为 M2，而不是伪装成确定估值结论。

同时，audit 的 8 项发现也非常有价值，说明当前并不是“自动完美”：

| audit 发现 | 数量 | 含义 |
|---|---:|---|
| 缺少实质证据的 Claim | 0 | 五条 Claim 均有 supports，最低闭环成立。 |
| 仅有 context 的 Claim | 0 | 没有用背景边冒充证据。 |
| 孤立 Evidence | 5 | 一部分预灌专家摘要/工具轨迹没有进入主线，需判断是否应删除、补连，或明确保留为旁证。 |
| 未被 addresses 补足的 Missing | 3 | 产能利用率、锂价敏感性、海外资源项目仍是后续研究任务，而不是已解决问题。 |
| 重复边 | 0 | 没有同一语义边重复堆积。 |
| 缺少 note 的边 | 0 | 每条边的具体作用可被阅读。 |

标题检查还提示 C3、C4、C5 的数字较多。它们并不一定错误：周期股的回撤、PE 和业绩预告区间本身可能需要数字定义判断。更合适的下一步不是一律删数字，而是观察是否能把“数据锚点”移到 rationale，使标题保留单一结论。

## 7. 当前结论与下一步

从这三个案例看，当前版本已经把证据图从“有节点和边”推进到更可审计的结构：

1. **关系语义更可靠**：药明旧图中的 Claim → Missing、Claim → Claim 边会被阻止；
2. **连接信息更可读**：赣锋当前样本 13/13 边有 note，而此前徐工/药明的边没有说明；
3. **Claim 覆盖更可检查**：audit 能明确指出没有实质边、孤立 Evidence 或未补足 Missing，而不是只显示一张看似完整的网络；
4. **不确定性得到保留**：赣锋把锂价敏感性、产能利用率和海外项目记录为 Missing，没有把它们硬写进强结论。

仍建议继续观察三项指标：

- 标题软警告是否能在模型收到 `title_check` 后下降；
- audit 中孤立 Evidence 的比例是否下降，但不以强行补边为代价；
- 同一标的在相同问题和数据窗口下，当前 prompt 是否稳定保留 “Claim → 实质边 → audit → export” 的完整闭环。

这些指标比 Claim 或边的绝对数量更能反映证据图是否真正提高了研究透明度。
