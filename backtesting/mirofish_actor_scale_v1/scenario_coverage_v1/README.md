# Scenario Branch Compiler v6 留出验证

## 设计

- 开发集：发现覆盖问题的 4 个八角色消融事件；
- 留出集：主实验中未进入消融的另外 4 个八角色事件，CN/US 各 2 个；
- 对照：相同、已密封的多智能体行动与金融决策，仅替换情景槽位编译器；
- 主指标：最终情景覆盖的有效决策角色比例；不读取市场结果标签。

## 结果

| 指标 | v5 | v6 | 变化 |
|---|---:|---:|---:|
| 情景角色覆盖率 | 43.8% | 96.9% | +53.1 pp |
| 有效决策角色覆盖率 | 45.5% | 100.0% | +54.5 pp |
| 遗漏的有效角色数 | 17 | 0 | 减少 100.0% |
| 平均情景分支数 | 3.25 | 4.00 | +23.1% |
| 结构完整率 | 100.0% | 100.0% | — |
| 不同角色组合数 | 3.25 | 4.00 | — |

v6 在 4 / 4 个留出案例中覆盖全部具有有效决策的角色；4 / 4 个案例不劣于 v5，其中 4 个案例得到改善。

## 代价与边界

仅重新编译情景，整组结果包含 4 次模型调用、23804 tokens，估算总成本 $0.0025；中位编译耗时 35.8 秒。
这是用户可见情景产物的工程覆盖指标，不是涨跌准确率。v6 通过确定性槽位保证角色多样性，模型仍负责生成触发条件、后果和失效条件；合成情景仍不是新证据或校准概率。
