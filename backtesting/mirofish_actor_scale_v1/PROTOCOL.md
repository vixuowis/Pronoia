# 多智能体规模与价值实验 v1

## 目标

本实验把两个容易混淆的问题分开回答：

1. **工程与产物价值**：4、6、8 个金融角色能否稳定运行，实际是否活跃，耗时如何，能否形成多方行动和情景分支；
2. **预测增量价值**：在相同事件输入和相同模型下，加入合成情景后是否改善严格 as-of 预测。

情景是合成假设，不是证据，也不能把单次分支频率解释为概率。

## 冻结设计

- 事件池：Pronoia `backtesting/events_cn_us_1000_v1.jsonl`；
- 主样本：CN/US × 6 类事件 × 每格 2 条，共 24 条；
- 角色预算：4/6/8 各 8 条，并在 CN、US 内各自平衡；
- 角色消融：4 个独立事件分别运行 4、6、8 个角色；主样本中相同的 8 人运行被复用，因此总计 32 次唯一推演；
- 选择方法：只读取事件文本，以固定 SHA-256 排序抽样；不读取 CAR 或方向标签；
- 图后端：`direct`，证据图直接编译为金融角色和 OASIS 配置，不经过 Zep；
- 快速运行：2 轮、1 次复制；最多 10 个角色；
- 方向资格赛：同模型的“仅事件文本”与“加入推演”配对；主指标为 T+3 三分类 Brier 差。

## 数据集准入规则

1000 条事件池仍会先用于工程覆盖，但只有通过输入质量审计的数据才能用于正式方向结论。审计不读取标签，检查：

- 标题+正文精确重复；
- `consensus / 预期 / 前值` 等占位文本；
- 缺失数值预期；
- 是否含可辨别的事件方向或 surprise；
- 事件类别与文本结构是否一致。

如果方向数据不通过准入，实验必须报告失败原因，不能用标签反向筛选“好看”样本。

## 复现

先启动本地服务：

```bash
make start
```

冻结清单并审计数据（不调用模型）：

```bash
make scale-manifest
make scale-audit
make scale-pilot
```

最后一条默认只打印付费计划。确认密钥和预算后运行：

```bash
make scale-pilot ALLOW_BILLABLE=1
make scale-run ALLOW_BILLABLE=1
make scale-score
```

中断后可重复执行相同命令：已完成任务和密封输出会被复用；失败任务会产生新的网关任务，不会伪装成成功。

## 结果文件

默认位于 `.data/experiments/actor-scale-v1/`：

- `manifest.json`：冻结样本、请求体、角色预算与文件哈希；
- `dataset-audit.json`：不看标签的数据质量准入；
- `runs.jsonl` / `runs.csv`：逐次工程指标；
- `predictions.jsonl`：方向资格赛的配对输出；
- `report.json` / `report.md`：机器可读与人类可读结果；
- `results.svg`：程序生成的可移植图；
- `raw/`：网关任务和模型输出，仅用于本地审计，不应全部提交到 PR。

PR 只需提交冻结清单、紧凑结果、评分说明和图；不提交 API 密钥、完整提示或可能含本地绝对路径的大型原始目录。

## 2026-09-01 冻结结果

- 32 / 32 次唯一推演完成；24 个主样本的中位 / P90 耗时为 79.5 / 99.5 秒；
- 4、6、8 角色均达到 100% 实际活跃，主样本有效结构化决策率为 97.0%；
- 32 次推演共 584 次成功模型调用、1,872,397 tokens，估算 $0.1319，平均 $0.0041/次；
- 同事件 4→8 角色时，平均自主行动 10.50→23.75，最终情景覆盖角色仅 4.00→4.25；
- 6 例 T+3 方向资格赛中，准确率不变，三分类 Brier 0.635→0.949，未通过；
- 既有 v7-C 的 12 个历史事件概率实验为弱正向：Brier 0.157292→0.152474，相对改善 3.06%。

因此当前可报告的增量价值是工程稳定性和多方行动覆盖；情景汇总器是角色扩容后的新瓶颈。
本轮数据不支持“推演改善 T+3 市场方向预测”。提交包位于
`upstreams/FEVER/backtesting/mirofish_actor_scale_v1/`，可用其中的 `verify_results.py`
离线复算。

## 解释规则

- 角色数与不同事件类型相关时，只能描述关联，不能称为角色数因果效应；角色数效应只看同事件 4/6/8 消融；
- 资格赛失败后，其余样本不得继续用于“证明”同一方向主张；应先修数据或冻结新方法，再使用未见标签的留出集；
- 小样本 bootstrap 区间用于表达不确定性，不等于顶会级统计证明；
- 可以把稳定性、耗时、角色活跃和机制覆盖表述为工程价值，把 Brier/准确率留给真正可评分的预测价值。
