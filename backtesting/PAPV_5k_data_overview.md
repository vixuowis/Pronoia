## 4. 质检结论

### 4.1 完整度 — PASS
- events / labels / research_context 三者严格对齐，无缺配。

### 4.2 推理链质量 — PASS
- rationale 中位数约 390 字，为真实多证据推理链；0 条缺失，0 条无断言。
- 抽样验证：引用公告原文 + T0 收益率/AR 分解 + pre-window 漂移 + 结构化净分，多证据交叉。
- 数据缺失时诚实降级为 neutral，不硬造高置信。

### 4.3 泄漏审计 — 抽样 + 全量均 PASS
- 全量扫描 151 处措辞命中，**无一条引用事件后已知结果**：
  - 事后结果引用：0
  - 跨期业绩引用：0
  - 后视口吻：0
  - 其余均为**合法的预事件信息**（pre5/pre20 事前行情）或**前瞻/条件句**（预测、非已知事实）。
- 推理链明确区分 `as_of` / `T0` 与 pre-window，只用预测时点可得信息。

### 4.4 已知不足
1. **CN/US 失衡**（88:12）。
2. **先验偏空**（down 2673 > up 2069）。
3. `event_strength` 全空。
4. **2026 上半年事件**需按评估时点切分防泄漏。
5. **长窗缺失**（t60 缺失 107）需掩码。
6. 言论族层面：上下文陈述偏向 CAR 族（from 早期单指标族集中问题，reward 已针对性修复）。
